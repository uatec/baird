Spike 3 Findings & Architecture Insights

This tech spike validates running the official @rive-app/canvas WebAssembly runtime in a browser / Web View for Baird's 10-foot UI layer:

  • Widevine DRM Video Layering: Rive renders to an HTML5 transparent canvas placed above the native/Web DRM video element. Under Wayland (Chromium / WPE WebKit), the browser composites the canvas and video using Wayland subsurfaces or zero-copy dmabuf hardware planes without tearing.
  • Vector Smoothness & Resolution Independence: Unlike bitmap UI elements, Rive vector geometry scales smoothly to 4K displays with subpixel antialiasing at negligible memory overhead (< 40KB asset size vs multi-megabyte sprite sheets).
  • State Machine Input Binding: The JS code directly drives Rive state machine inputs (`isPlaying`, `trackProgress`, `volume`, and triggers). Keystrokes from TV CEC remotes map straight to state machine values with instant 60fps response.
